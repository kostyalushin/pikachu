# Пикачу: Блочная буря

Трёхмерная браузерная игра на Three.js. Пять блочных арен, пять всё более сильных Райчу, собираемые заряды молнии, двойной прыжок и восстановление здоровья.

Запуск: `npm start`, затем открыть http://localhost:4173. Установка зависимостей не требуется: Three.js включён в `dist/vendor`.

Проверка правил: `npm test`.

## Бесплатный хостинг и автодеплой

Игра готова для GitHub Pages. На GitHub Free репозиторий должен быть публичным. Для публикации нужен только каталог `dist`: сервер, база данных, сборка и установка npm-зависимостей не требуются.

В репозиторий включён workflow `.github/workflows/deploy-pages.yml`:

- При каждом push в `main` запускаются игровые тесты и проверка синтаксиса JavaScript.
- После успешной проверки содержимое `dist` публикуется в GitHub Pages.
- Для pull request выполняются только проверки, без публикации.
- Повторный деплой можно запустить вручную во вкладке **Actions**.

При первом подключении в **Settings → Pages → Build and deployment → Source** нужно выбрать **GitHub Actions**. После первого успешного запуска адрес игры появится в **Settings → Pages** и в результате workflow. Секреты, персональный токен и отдельный аккаунт хостинга для workflow не нужны: используются временные права GitHub Actions.

Все ссылки на ресурсы относительные, поэтому игра работает и в подпапке репозитория на `github.io`. Вместе с игрой публикуется локальная копия Three.js. Папка `.openai` относится к предыдущему размещению в Sites и в GitHub Pages не загружается.

Если исходники должны остаться приватными на бесплатном тарифе GitHub, альтернативный вариант — Cloudflare Pages с Git-интеграцией: ветка `main`, каталог публикации `dist`, без команды сборки.

Документация: [создание GitHub Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site), [публикация через Actions](https://docs.github.com/en/pages/getting-started-with-github-pages/using-custom-workflows-with-github-pages), [лимиты бесплатного Cloudflare Pages](https://developers.cloudflare.com/pages/platform/limits/).

Управление: WASD или стрелки — перемещение, Space — прыжок, E/F — молния, Esc — пауза. Есть экранные кнопки для телефона. Для игры требуется WebGL. Звук включается кнопкой ♪.

Золотые кристаллы дают по три заряда; зелёный жетон открывает двойной прыжок. Молния наносит 24 урона на земле и 36 в воздухе. Перепрыгивай расширяющиеся кольца Райчу. На следующих уровнях босс быстрее, прочнее и получает дополнительные атаки. Победа на пятом уровне завершает игру.
